## 3. 核心组件样式

### 按钮（轻立体糖果按钮）
- 形状：圆角 `16px`；渐变填充（顶亮→底主色）；顶部 `2px` 内高光 + 底部 `6px` 同色深一档「厚度」+ 柔和投影
- 交互：hover 上浮 `2px`、亮度+；active 下移 `4px`、厚度收为 `2px`（真实按压感）；禁用 `60%` 透明
- 变体：Primary（品牌紫）/ Accent（琥珀，用于掷骰）/ Ghost（描边）/ 尺寸 S·M·L

### 卡牌 Card
- 圆角 `22px`，白底，1px 浅描边，柔和分层投影；hover 微抬升 `2px`

### 弹窗 Modal
- 圆角 `28px`，背板毛玻璃模糊；入场 `scale .96→1 + fade`，`320ms` pop 缓动；顶部可放可爱图标徽章

### 玩家信息栏 Player Bar
- 卡片：圆角头像（飞机圆形 token）+ 昵称 + 颜色标签 + 「到达 X/4」进度 + 行动中高亮（外发光脉冲动画）

### 3D 骰子（核心交互组件）
- 形态：96×96 立方体，圆角 `22px`，糖果白面（`#fff→#F1EDFA` 体积渐变）+ 顶部内高光 + 底部深色描边，呈现软糖立体感
- 点数：6 面标准布局（对面和=7：1-6 / 3-4 / 2-5），圆点用琥珀强调色 `#FFB23E` + 径向高光
- 待机：微倾 `rotateX(-22deg) rotateY(24deg)` 露出立体感；轮到玩家时可轻微浮动提示「可投掷」
- 投掷动画（总时长 `1000ms`，见 §5）：在<b>棋盘中央舞台</b>蓄力下蹲 → 跳起空中翻转多圈 → 落地回弹 → 定格显示点数；地面阴影同步缩放 / 淡入淡出
- 降级：尊重 `prefers-reduced-motion`，关闭翻滚、瞬时旋转到目标面

## 4. 飞行棋主界面布局
- **顶栏**：游戏名 `✈️ 飞行棋大冒险` + 轮次胶囊「第 N 轮」+ 设置
- **中部**：十字形棋盘（圆角格、四色基地、中心「终点」星/云）、Q 版飞机 token（圆润带高光、可显示编号）
- **侧栏**：4 张玩家卡 + 大骰子（显示点数，掷骰按钮）+ 行动日志
- **响应式断点**：≥1024 左右布局；<1024 棋盘在上、面板在下

---

## 5. 动画 / 过渡规范（过渡时长）
| 名称 | 时长 | 缓动 | 用途 |
|---|---|---|---|
| 快速微交互 | `120ms` | ease | hover、focus |
| 状态切换 | `200ms` | ease-soft(.4,0,.2,1) | 选中、禁用切换 |
| 面板/弹窗入场 | `320ms` | pop(.34,1.56,.64,1) | 弹窗、卡片出现 |
| 3D 骰子投掷 | `1000ms` | 蓄力(120ms)→跳起翻转(≈520ms)→落下回弹(≈360ms) | 棋盘中央掷骰 |
| 飞机移动 | `360ms/格` | ease-in-out | 走子（多格错峰） |
| 撞击 / 胜利 | `480ms` | pop 回弹 | 撞机弹飞、胜利庆祝 |

- 全局尊重 `prefers-reduced-motion`（用户开启减少动态时降级为瞬时切换）

## 6. 立体质感手法（实现清单，给后续开发参考）
- 分层柔影：`0 2px 6px` + `0 8px 20px` + `0 16px 40px` 三段投影
- 体积渐变：每个色块「顶亮→底主色」模拟光照
- 内高光：顶部 `inset 0 2px 0 rgba(255,255,255,.5)`
- 按钮厚度：底部实色「厚度条」+ active 压扁
- 飞机 token：径向高光 + 底部深色描边，呈现小球体感
